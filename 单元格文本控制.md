
单个单元格内**没有真正的 Paragraph / ParagraphFormat 对象**，所谓“段落化控制”只能靠以下 API 模拟。

---

## 一、分段与文本读写

| API                          | 说明                            |
| ---------------------------- | ------------------------------- |
| `Range.Value2`             | 读写单元格文本，最快            |
| `Range.Value`              | 读写值，会类型转换              |
| `Range.Formula`            | 写入公式，可用`CHAR(10)` 换行 |
| `Range.Text`               | 只读，返回显示文本，受列宽影响  |
| `Range.Characters`         | 引用单元格内部分字符            |
| `Characters.Text`          | 读写部分文本                    |
| `Range.ClearContents`      | 只清除文本，保留格式            |
| `Range.NumberFormat = "@"` | 设为文本格式                    |

```vba
Dim rng As Range
Set rng = ThisWorkbook.Worksheets("Sheet1").Range("A1")

rng.Value2 = "第一段" & vbLf & "第二段" & vbLf & "第三段"
```

## 二、单元格内换行符与分段处理

| API / 函数                       | 说明                    |
| -------------------------------- | ----------------------- |
| `vbLf` / `Chr(10)`           | 单元格内换行符          |
| `Split`                        | 按`vbLf` 拆成段落数组 |
| `Join`                         | 段落数组合并回多行文本  |
| `InStr`                        | 判断是否包含换行        |
| `Replace`                      | 替换换行符或段落文字    |
| `Len`                          | 计算段落长度            |
| `Mid` / `Left` / `Right`   | 截取段落文字            |
| `Trim` / `LTrim` / `RTrim` | 去掉段落首尾空格        |

```vba
Dim arr() As String
arr = Split(rng.Value2, vbLf)

rng.Value2 = Join(arr, vbLf)
```

## 三、整个单元格的段落外观控制

| API                            | 说明                                                                              |
| ------------------------------ | --------------------------------------------------------------------------------- |
| `Range.WrapText`             | 自动换行，多段显示必须开                                                          |
| `Range.HorizontalAlignment`  | 水平对齐：`xlLeft`、`xlCenter`、`xlRight`、`xlJustify`、`xlDistributed` |
| `Range.VerticalAlignment`    | 垂直对齐：`xlTop`、`xlCenter`、`xlBottom`、`xlJustify`、`xlDistributed` |
| `Range.IndentLevel`          | 整体缩进级别，`0~15`                                                            |
| `Range.AddIndent`            | 自动缩进                                                                          |
| `Range.InsertIndent`         | 插入缩进                                                                          |
| `Range.Justify`              | 两端对齐调整                                                                      |
| `Range.Orientation`          | 文字方向                                                                          |
| `Range.ShrinkToFit`          | 缩小字体填充                                                                      |
| `Range.ReadingOrder`         | 阅读方向                                                                          |
| `Range.RowHeight`            | 行高                                                                              |
| `Range.EntireRow.AutoFit`    | 自动行高                                                                          |
| `Range.ColumnWidth`          | 列宽                                                                              |
| `Range.EntireColumn.AutoFit` | 自动列宽                                                                          |

```vba
With rng
    .WrapText = True
    .HorizontalAlignment = xlLeft
    .VerticalAlignment = xlTop
    .IndentLevel = 1
    .EntireRow.AutoFit
End With
```

## 四、按“段落”设置部分文字格式

只能通过 `Range.Characters` 按字符范围设置，不能按段落设置对齐、缩进、行距。

| API                                    | 说明         |
| -------------------------------------- | ------------ |
| `Range.Characters(Start, Length)`    | 引用某段文字 |
| `.Characters.Font`                   | 设置该段字体 |
| `.Font.Name`                         | 字体         |
| `.Font.Size`                         | 字号         |
| `.Font.Bold`                         | 加粗         |
| `.Font.Italic`                       | 斜体         |
| `.Font.Underline`                    | 下划线       |
| `.Font.Color`                        | 颜色         |
| `.Font.Strikethrough`                | 删除线       |
| `.Font.Superscript` / `.Subscript` | 上标 / 下标  |

```vba
Sub FormatCellParagraphs()
    Dim rng As Range
    Dim arr() As String
    Dim i As Long, p As Long

    Set rng = ThisWorkbook.Worksheets("Sheet1").Range("A1")
    rng.Value2 = "标题" & vbLf & "正文第一段" & vbLf & "正文第二段"
    rng.WrapText = True

    arr = Split(rng.Value2, vbLf)
    p = 1

    For i = LBound(arr) To UBound(arr)
        If Len(arr(i)) > 0 Then
            With rng.Characters(p, Len(arr(i))).Font
                If i = 0 Then
                    .Bold = True
                    .Size = 12
                    .Color = vbRed
                Else
                    .Bold = False
                    .Size = 10
                    .Color = vbBlack
                End If
            End With
        End If
        p = p + Len(arr(i)) + 1   ' +1 是换行符
    Next i
End Sub
```

## 五、段落间距、缩进、项目符号的模拟

单元格内没有 `SpaceBefore`、`SpaceAfter`、`LineSpacing`、`Bullet`。

| 效果          | 模拟方式                                     |
| ------------- | -------------------------------------------- |
| 段前 / 段后距 | 插入空行：`vbLf & vbLf`                    |
| 行距          | 设置`RowHeight`，配合 `WrapText`         |
| 段落缩进      | 整体用`IndentLevel`，单段用空格 / 全角空格 |
| 项目符号      | 手动加`• `、`- `、`1. `               |
| 编号          | 手动写`1.`、`2.`                         |
| 首行缩进      | 段首加空格                                   |

```vba
rng.Value2 = "第一段" & vbLf & vbLf & "第二段"
rng.WrapText = True
rng.RowHeight = 45
```

## 七、最常用 TOP 清单

`Range.Value2`、`Range.Formula`、`Range.Characters`、`Characters.Font`、`vbLf`、`Split`、`Join`、`Replace`、`InStr`、`WrapText`、`HorizontalAlignment`、`VerticalAlignment`、`IndentLevel`、`RowHeight`、`EntireRow.AutoFit`、`Font`、`NumberFormat`。

---

总结：
单个单元格内段落化控制的核心是：
**用 `vbLf` 分段，用 `WrapText` + 对齐 + 缩进 + 行高控制整体段落外观，用 `Range.Characters` 按字符范围控制每段文字格式。**
单元格本身不支持真正的段落格式 API。
